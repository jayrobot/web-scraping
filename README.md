# web-scraping

experiments in PowerShell web scraping

## Scrape-WABY-playlist.ps1

This script scrapes the hourly playlists from the [WABY Playlist page](https://www.939waby.com/onair/played/) and outputs the results to a daily CSV file. The site only maintains one week of data, so the script is designed to run weekly. It is also required to be run on a Monday, and it retrieves the playlists for the previous week.
